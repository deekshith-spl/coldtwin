# ❄️ ColdTwin — Cold Storage Monitoring

ColdTwin is a web-based prototype designed to help users understand cold-storage chamber conditions and identify potential energy inefficiencies through a centralized dashboard.

## 🎯 Project Overview

Cold-storage facilities need to maintain suitable environmental conditions while managing energy consumption. ColdTwin aims to make important chamber information easier to monitor and interpret.

## ✨ Features

- **Chamber Dashboard:** Displays chamber-related information in a centralized interface.
- **Temperature Monitoring:** Presents target temperature and available temperature readings.
- **Humidity Monitoring:** Displays humidity information to help users understand chamber conditions.
- **Energy Waste Estimation:** Shows estimated energy waste to help identify potential inefficiencies.
- **Visual Interface:** Organizes key information into a dashboard for easier interpretation.

> Note: The accuracy of energy-waste estimates depends on the underlying data and calculation method. This project is a prototype, not a validated industrial control system.

## 🛠️ Technology Stack

- Frontend: TypeScript, Vite
- Styling: Tailwind CSS

## 🚀 Getting Started

### Prerequisites

- Git
- Node.js and npm

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ColdTwin.git
cd ColdTwin
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** These commands assume the project uses the standard Vite development workflow. Verify the available scripts in `package.json`.
